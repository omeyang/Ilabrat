# 工作台快速入门

准备一个已有的 gRPC 服务和与它匹配的 Buf 工作区。下面以 `127.0.0.1:50051` 上的明文 Echo 服务为例，示例方法是 `echo.v1.EchoService/Echo`，请求和响应都有 `text` 字段。实际操作时请使用自己的地址和字段。

1. 在 DSH 侧栏打开 **Ilabrat · gRPC 工作台**。检查左侧目录，点击「加载 schema」。Buf 会解析模块和导入。点击「校验」运行 `buf lint`，点击「编译」可单独生成描述符。
2. 在「方法」中过滤并选择 RPC。点击「填入 schema 模板」，再把示例值改为真实请求。按钮会覆盖当前编辑器内容。
3. 填写服务地址 `127.0.0.1:50051`，将传输设成「明文 h2c」。使用证书受系统信任的 TLS 服务时，保留默认 TLS。需要鉴权时，在 Metadata 页签填入 JSON 字符串键值对。
4. 在「请求体」中填入 `{"text":"hello"}`，点击「发送请求」。工作台会重新编译 schema，再用该描述符调用 grpcurl。
5. 检查「结果」中的响应、gRPC 状态、退出码和耗时。对本例，响应的 `text` 应等于 `hello`。在「断言」里填路径 `/text`、期望值 `"hello"`，再次发送可直接验证该字段。

常用的地址和传输方式可以通过「保存环境」命名，下次从「选择环境」切换。需要重复运行的请求可[保存为用例](Test-cases.md)。
